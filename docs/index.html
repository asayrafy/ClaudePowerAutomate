How it works

Nothing is built until you confirm the specification. If it is not right, you correct it and Claude revises it.

  1. DescribeIn chat, with a procedure or policy, or with the Excel intake workbook.
  2. Claude draftsA Flow Specification: lists, flows, triggers, steps, people and outcomes.
  3. You confirmReply "yes", or correct it. Claude builds nothing before this.
  4. Claude buildsOne .zip package per flow, plus flow 0 for the lists.
  5. You importThrough Import Package (Legacy), with your own connections.
  6. You testRun the test cases, sign off and keep the Build Sheet.

What you receive

The skill has one output: import packages for Power Automate, with everything you need to install and test them.

Flow packages

One .zip per flow, numbered in import order and checked by script before delivery.

Flow 0

A package that creates the SharePoint lists and columns. Import and run it first.

Install Checklist

A page with a tick box for every import, set-up and test step, written for your build.

Build Sheet

The record of what was built, how to test it and what remains open. Keep it as your change record.

Built for everyday business processes

Approvals, notifications, reminders, requests, registers, trackers and hand-offs in Microsoft 365.

Three ways in

Write it in chat, attach a written procedure, or fill in the intake workbook, which converts the same way every time.

You stay in control

Claude never signs in to your tenant and never asks for a password. You import the packages yourself.

Fits any organisation

Time zone, date format, currency and approval authority are settings. Claude asks for any a build needs.

Standard connectors

SharePoint, Outlook, Office 365 Users, Teams and Approvals. Premium connectors are flagged, never used silently.

Safe by design

Try and Catch failure alerts, loop protection on triggers, and test messages sent only to you.

Auditable

Every build leaves a confirmed specification and a Build Sheet that records what was tested and what was not.

Install the skill in Claude

The skill needs a Claude plan that supports custom skills, with code execution turned on. Check Anthropic's help article for the plans that currently support skills.

Web and desktop apps

Claude

  1. Download the skill (.zip). Do not unzip it.
  2. In Settings > Capabilities, turn on Code execution and file creation (in newer layouts, Create and edit files).
  3. Open Customize > Skills, select +, then Create skill > Upload a skill, and choose the .zip.
  4. Make sure power-automate-builder is switched on.
Team and Enterprise

For a whole organisation

  1. An organisation owner opens Organization settings > Plugins & skills, selects Add > Upload a skill, and chooses the .zip.
  2. On the Policy tab, Cloud code execution and file creation and Skills must be on.
  3. The skill is then on for every member, and each member can switch it off. Read more.
Command line

Claude Code

Copy the skill folder into your personal skills folder. If it does not appear, run /reload-skills.

macOS or Linux

git clone https://github.com/asayrafy/ClaudePowerAutomate.git
mkdir -p ~/.claude/skills
cp -r ClaudePowerAutomate/power-automate-builder ~/.claude/skills/
python3 -m pip install openpyxl

Windows (PowerShell)

git clone https://github.com/asayrafy/ClaudePowerAutomate.git
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse ClaudePowerAutomate\power-automate-builder "$HOME\.claude\skills\"
py -m pip install openpyxl
Desktop agent

Cowork

Cowork has its own Customize > Skills area, where you add the skill in the same way. Skills your organisation provisions appear there automatically.

Your organisation's settings

To stop Claude asking for the time zone, date format, currency and approval authority, set them once in the Organisation settings table in SKILL.md, zip the folder again and upload it.

Ask Claude to build a flow

Start a new chat for each process. Always include the SharePoint site address. The helper page can write this message for you.

Import the flows into Power Automate

Your Install Checklist carries these steps with your real file names. Import in number order: flow 0 creates the lists, so it goes first.

Step 1

Prepare

Sign in to make.powerautomate.com, check the environment, and make sure your connections work.

Step 2

Import

My flows > Import > Import Package (Legacy). Upload the .zip, select your connection for each row, then Import.

Step 3

Create the lists

Open flow 0, select Run, and check that every list step is green and the lists exist.

Step 4

Switch on and test

Set any values listed in the Build Sheet, Save, Turn on, share with your co-owner, then run the test cases.

Something not working? See the troubleshooting table in the User Guide, or paste the exact error into the same chat with Claude.
